## What's new

- LFM3 1.7B is now available in the on-device model catalog.

## Fixes

- On-device models now run on a newer LiteRT-LM runtime, fixing loads that failed with a weights error.
- On-device models are pinned to exact, verified file revisions, so a catalog refresh can no longer point at weights the app cannot run.
- On Android, downloaded on-device models that no longer match the catalog are cleaned up automatically instead of failing to load.
