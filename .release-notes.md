## What's new

- `/context` shows where the model's context window goes, with a per-run breakdown of the system prompt, tools, MCP servers, skills, memory, plugins, messages, and free space.
- Subagent tasks now run as their own chats — they appear in the sidebar, inherit the parent chat's model and permissions, and can be opened from the parent trace.

## Improvements

- Delegation is visible in the parent trace with a direct link to the child chat.
- Once a subagent task is approved, its internal tool calls run without repeated approval prompts.
- ChatGPT/OpenAI sign-in is more reliable: token refreshes no longer race, model lists stay in sync per account, and stale saved models switch to a current one.
- Tool traces now use clearer icons and previews for video, audio, and mix tools.
- Video frame inspection accepts a single timestamp, several timestamps, or both together, and returns a still or a contact sheet.
- Large videos can be transcribed directly without extracting the audio first.
- Harness setup now shows the real LAN IP, supports direct OpenCode URL/password connections, allows editing ACP bridge addresses after pairing, and gives clearer connection errors.
- The bridge installer shows download progress, retries stalled transfers, and explains that `mabridge` runs in the foreground.

## Fixes

- Fixed video inspection failures when `time` and `times` were supplied together.
- Fixed localhost harness connections from Termux and other local setups.
- Fixed OpenCode provider errors not appearing in chat and structured harness errors being shown raw.
- Fixed expired ChatGPT credentials not surfacing a clean reconnect prompt.
- Fixed keyboard spacing staying behind after sending a message.
