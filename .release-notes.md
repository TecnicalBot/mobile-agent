## What's new

- Voice models can now download in the background with live progress and a notification.
- Long-press selection now covers an entire reply, including multiple paragraphs and lists, while code blocks and tables keep their cards and copy buttons.

## Improvements

- Voice, on-device, and app-update buttons now show live download percentages.
- Models without tool support now show a clear notice instead of claiming to run tools.
- Plugin import now explains missing headers and validates the plugin before saving.

## Fixes

- Fixed on-device models freezing around 85% or failing because of stale catalog URLs.
- Fixed stale voice download progress and notifications after canceling or reopening the Voice screen.
